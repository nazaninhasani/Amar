# راهنمای اجرای فاز دوم پروژهٔ آمار

## موضوع
مسیر الف: NHANES 2021–2023.
بررسی احتمال‌ها و توزیع‌های مرتبط با وزن بدن، سن و جنس ثبت‌شده
در افراد ۲۰ سال و بیشتر.

## محیط اجرای بررسی‌شده
این نوت‌بوک با Python 3.15.0 اجرا شده است.
نسخهٔ کتابخانه‌ها در requirements-phase2.txt ثبت شده است.

## داده‌های موردنیاز
دو فایل زیر باید داخل پوشهٔ data قرار داشته باشند:

- DEMO_L.xpt
- BMX_L.xpt

نام فایل‌ها و بزرگی و کوچکی حروف پسوند باید با کد یکسان باشد.
داده‌ها در اجرای نوت‌بوک به‌صورت خودکار دانلود نمی‌شوند.

مستندات رسمی و دسترسی به داده‌ها:

- https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/DEMO_L.htm
- https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/BMX_L.htm

## نصب وابستگی‌ها
از ترمینال ریشهٔ پروژه اجرا کنید:

```bash
python -m pip install -r requirements-phase2.txt
```

در VS Code، پشتیبانی Python و Jupyter باید نصب باشد.
برای نوت‌بوک، همان محیط پایتونی را انتخاب کنید که وابستگی‌ها
در آن نصب شده‌اند.

## اجرای تحلیل
1. پوشهٔ Amar را در VS Code باز کنید.
2. فایل notebooks/phase2_analysis.ipynb را باز کنید.
3. کرنل پایتون مناسب را انتخاب کنید.
4. Restart Kernel و سپس Run All را اجرا کنید.
5. پس از پایان موفق اجرا، نوت‌بوک را ذخیره کنید.

فایل src/nhanes_analyzer.py نیز باید در ساختار پروژه موجود باشد.
نوت‌بوک از ریشهٔ پروژه یا پوشهٔ notebooks قابل اجراست.

## آماده‌سازی داده
شناسه‌های SEQN از نظر یکتایی بررسی و دو فایل با اتصال داخلی
ادغام می‌شوند. افراد با سن حداقل ۲۰ سال انتخاب می‌شوند.
موارد فاقد اطلاعات لازم کنار گذاشته شده و جنس ثبت‌شده به
کدهای ۱ و ۲ و وزن نمونه‌گیری معاینه به مقادیر مثبت محدود می‌شود.

نمونهٔ نهایی با داده‌های استفاده‌شده شامل ۵۹۸۳ نفر است.
نقاط دورافتاده صرفاً علامت‌گذاری شده‌اند و حذف نشده‌اند.

## بازتولید شبیه‌سازی
